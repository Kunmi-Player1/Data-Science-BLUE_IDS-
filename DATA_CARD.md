# Data Card — CSE-CIC-IDS2018 (Processed CSVs)

**Dataset:** CSE-CIC-IDS2018  
**Official page:** https://www.unb.ca/cic/datasets/ids-2018.html  
**AWS Registry:** https://registry.opendata.aws/cse-cic-ids2018/

**What this is (plain English)**  
A realistic enterprise-network dataset with **7 attack scenarios**. We’ll use the **Processed Traffic Data for ML Algorithms** CSVs, which are **flow-feature tables** generated by **CICFlowMeter-V3** (~80+ features). Perfect for training/testing ML-based IDS on attack vs benign traffic.

**Local path (raw):**  
`data/raw/ids2018/Processed Traffic Data for ML Algorithms/`

**Team choices for Module 1:**  
- No checksums and no row-count code by design.  
- Raw data stays out of Git (lives under `data/` which is git-ignored).
